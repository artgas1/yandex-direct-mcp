# API Яндекс Директа

Всё делается одной командой `yandex-direct-mcp`. Она не отдельная обёртка над
Директом, а тот же код, что и MCP-сервер: одна спека, один транспорт, одни
единицы измерения.

## Установка и токен

```bash
npx yandex-direct-api-mcp help
export YANDEX_DIRECT_TOKEN="…"     # OAuth Яндекса, scope direct:api
```

Токена нет → https://oauth.yandex.ru/, приложению нужна одобренная заявка на
доступ к API Директа. Агентствам дополнительно нужен `YANDEX_DIRECT_LOGIN` —
логин клиента, **не** электронная почта.

## Три команды

```bash
yandex-direct-mcp catalog --service campaigns     # что вообще есть
yandex-direct-mcp describe campaigns.get          # какие параметры
yandex-direct-mcp call campaigns.get --FieldNames Id --FieldNames Name
```

Параметры: `--Имя значение`, повтор даёт массив, `--Имя@json '{"…"}'` для
вложенных объектов. Коды возврата: `0` успех, `1` отказ API, `2` ошибка вызова,
`3` изменение запрещено, `4` нет токена.

## Порядок работы

1. `catalog` — найти службу и метод.
2. `describe` — узнать параметры и допустимые значения.
3. `call` — вызвать. Отказ приходит JSON-ом в stdout, читать один поток.
4. Не угадывай значения `FieldNames`: `fields <ИмяПеречисления>` либо просто
   пошли заведомо неверное — Директ перечислит допустимые в тексте ошибки.

## Что команда делает за тебя

Это не удобства, а места, где ручной запрос ошибается молча.

- **Суммы приводит к валюте счёта.** API отдаёт деньги умноженными на миллион всегда:
  `DailyBudget.Amount = 1000000000` — это 1000 единиц валюты счёта. Команда пересчитывает и
  перечисляет в ответе, какие поля пересчитала.
- **Сохраняет длинные идентификаторы.** `Id` объявления бывает из девятнадцати
  цифр и не помещается в число JavaScript. Испорченный `Id` Директ принимает и
  отвечает `{"result":{}}` — то есть «объявления нет» вместо ошибки.
- **Отличает отказ от успеха по телу, а не по коду.** Ошибка приезжает и с
  HTTP 200, и с 202, и с 400 — а у отчётов 201 и 202 означают «ещё считается».
- **Ждёт отчёт.** 201 → 202 → 200 с повтором по тому же `ReportName`.
- **Ставит и снимает обёртку `Items`** по графу типов, а не по виду значения.
- **Считает баллы** — расход и остаток в каждом ответе.

## Ловушки, проверенные на живом кабинете

1. **Список кампаний неполон.** Кампании Мастера кампаний в `campaigns.get` не
   попадают вовсе — ни списком, ни по явному `Ids`, ответ пустой и без ошибки.
   На живом кабинете такая кампания видна только отчёту и может нести основную долю показов.
   **Состав кабинета бери отчётом `CAMPAIGN_PERFORMANCE_REPORT`, а не списком**
   — в MCP это делает инструмент `direct_inventory`, склеивающий оба источника.
2. **Версия пути меняет данные.** По `v501` кампании приходят с
   `Type=UNIFIED_CAMPAIGN`, по `v5` те же самые — с `TEXT_CAMPAIGN`. Запросишь
   `TextCampaignFieldNames` на `v501` — глубокие поля не придут, и ошибки не
   будет. Умолчание `v501`; переключается `DIRECT_API_VERSION=v5`.
3. **Предупреждение — это применено.** В ответе на `update` различай по
   `Errors`, а не по «есть ли что-то»: `Warnings` означает «применено с
   замечанием». Счёт по наличию любого содержимого даёт «отклонено всё» там,
   где применилось всё.
4. **Пропущенное поле в `update` не снимает его**, а оставляет как было.
   Ответ без ошибок не доказывает изменение — перечитай поле.
5. **Пагинация.** Вернулось ровно `Page.Limit` строк и есть `LimitedBy` —
   значит есть ещё. Крути `Offset`.
6. **Минус-слова лежат в той же строке `Keyword`.** Поиск по подстроке даёт
   ложные попадания: `-бесплатно` в минус-списке читается как таргетинг на
   «бесплатно». Сначала отбрось токены на `-`.
7. **`AttributionModels` только вместе с `Goals`** — иначе отказ.
8. **`Filter` в отчёте всегда массив**, даже для одного условия.
9. **Баллы восстанавливаются порциями в течение дня**, а не разом в полночь.
   Исчерпал — опрашивай раз в две-три минуты, а не жди суток.
10. **Пустой результат ничего не доказывает.** У Директа он одинаково означает
    «нет такого», «не отдаётся этим методом» и «идентификатор испорчен».

## Изменение выключено

Меняющие методы требуют `DIRECT_ALLOW_WRITES=1`. Подтверждающего шага у API
нет: `suspend` останавливает показы в момент вызова, `archive` убирает кампанию
из работы, `delete` необратим, а на другом конце — деньги. Есть песочница:
`DIRECT_SANDBOX=1` (нужна отдельная регистрация и отдельный токен).
